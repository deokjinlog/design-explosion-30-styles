연서 대화형 — 3층 조립(Zen Garden)으로 만든 30 스타일

새 파이프라인 실증: HTML 통짜 생성이 아니라 스켈레톤 1개 + base 1개 + tokens 30 + signature 6을 조립. 30장의 body가 바이트 동일 — 콘텐츠 동일성이 구조적 보장.
coverage-lint 30/30 body 바이트 동일 30/30 signature 6 · 토큰전용 24
이건 도구의 새 엔진이다. 예전엔 스타일마다 HTML을 통째로 만들어 "같은 6마디"를 프롬프트로 부탁했는데(부탁은 샌다), 여기선 DOM(스켈레톤)을 고정하고 CSS 3층만 갈아끼운다: base(원형 B 공용·토큰 먹음) + tokens/NN(색·형태·밀도, 원형 무관·재사용) + signature/NN--B(구조가 강한 스타일만 — 04·05·07·09·10·18). 그래서 30장 body가 문자 그대로 동일하고 콘텐츠 드리프트가 물리적으로 불가능하다. 게이트도 archetype-lint가 아니라 selector-coverage(환각 셀렉터·누락 영역 = CSS 실패 전 집합) 하나로 대체.

알려진 후속(품질 패스): ① 토큰전용 24개 중 구조가 필요한 것들에 signature 추가 ② 웹폰트 로딩(@import) — 지금은 토큰 폰트가 시스템 폴백. 파이프라인 자체는 확정.
