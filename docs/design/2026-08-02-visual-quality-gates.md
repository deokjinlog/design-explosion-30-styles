# 시각 품질 게이트 — LLM이 만든 CSS를 어떻게 검증하나

> **문제**: 구조 게이트(`coverage-lint`)는 "CSS가 스켈레톤에 제대로 배선됐나"만 본다. LLM이 저작한 시그니처 CSS가 **환각 0·누락 0으로 PASS 나도, 렌더링이 못생기거나 글자가 안 읽힐 수 있다.**
> **증거**: 사용자가 "14·15·16·21… 다 비슷해 보인다"를 잡았을 때 coverage는 **30/30 PASS**였다. 자동 게이트는 다 통과인데 눈으로 보니 문제 = **자동으로 안 잡히는 시각 품질**을 사람 눈이 잡은 것.

날짜: 2026-08-02 · 관련 [3층 전환](2026-07-26-zen-garden.md) · [출처·서체 접지](2026-07-26-type-and-source-grounding.md)

---

## 핵심 — 렌더링 없이는 "보기에 어떤가"를 못 판단

지금 막힌 진짜 이유는 하나: **헤드리스 브라우저가 없어 픽셀을 못 만든다.** 픽셀이 없으면 판단할 대상 자체가 없다. 고수들은 예외 없이 **헤드리스 크로미움(Playwright/Puppeteer)으로 실제 렌더**부터 하고 그 위에 검사를 쌓는다.

- **크로미움** = 브라우저 엔진(도구). 창 없이 백그라운드에서 진짜 렌더(픽셀 생성).
- **Playwright** = 크로미움을 코드로 조종하는 리모컨(MS 오픈소스). 내부적으로 **CDP(Chrome DevTools Protocol)** JSON 메시지로 통신. `page.screenshot()` → `Page.captureScreenshot`, `page.evaluate()` → `Runtime.evaluate`.

---

## 렌더 위에 쌓는 3겹 — "누가" 판정하나

| 겹 | 뭘 판정 | 누가 (AI냐?) | 기준 출처 |
|---|---|---|---|
| **① 규칙 검사** | 대비 4.5:1 미만? 가로 오버플로? 타깃 44px 미만? | Playwright 측정 + 스크립트 규칙 — **AI 아님(수학)** | **WCAG 국제 표준** |
| **② 비주얼 회귀** | "이전 정상 그림" vs "지금 그림" 픽셀 diff | 이미지 대조 도구 — **AI 아님** | 기준 = 승인된 이전 스냅샷 |
| **③ VLM 심판** | 깨졌나·읽히나·이 스타일 맞나(전체 판단) | 눈 달린 **AI(VLM)** | 사람이 준 **루브릭** |

- **①**은 결정적. 렌더된 실제 색으로 대비 계산(토큰·시그니처 override 전부 반영). 베이스라인 불필요.
- **②**는 콘텐츠 고정(body 바이트 동일)이라 유리 — diff = 순수 CSS 변화. **"내가 고쳤는데 딴 데가 실수로 망가졌나"** 부작용 감지. 새 스타일엔 비교 대상이 없어 못 씀(회귀 전용).
- **③**은 규칙으로 못 짜는 전체적 판단. 스크린샷을 VLM에게 주고 루브릭으로 채점. "다 비슷"도 여기서 자동으로 잡힌다.

**도구(크로미움·Playwright) = 그림 만들고 잼. AI(VLM) = 그림 보고 판정.** 별개 층.

## 기준은 임의가 아니라 근거에서 온다

이 프로젝트의 철학(원형=Enrico, 도메인=Mind2Web, 스타일=디자인시스템)과 동일 — **감이 아니라 접지.**

- **① 규칙 = WCAG** (W3C 제정, HTML·CSS 만든 그 조직). 대비 4.5:1(AA)·타깃 44px·리플로는 발명이 아니라 표준에서 선택. 미국 ADA/508·EU EN 301 549·한국 KWCAG로 **법제화**돼 공신력·객관성 최상. 자동화 가능해 도구 생태계(axe·Lighthouse).
- **③ VLM 루브릭 = 세 근거를 질문으로 엮음**:
  - 가독성·깨짐 ← WCAG·기본 UX(Nielsen 10 휴리스틱)
  - **스타일 충실도 ← 우리 `type-and-source` 문서의 사조별 시그니처/forbidden 표** (예: "Carbon이면 radius 0·소프트 섀도 없어야")
  - 변별력 ← 프로젝트 목표(30개가 구별돼야)

VLM 심판을 신뢰성 있게 만드는 실무 장치: **취향을 이진 체크로 쪼갬**(예쁜가?→radius 0인가?) · **사람 라벨로 보정(calibration)** · **여러 번 투표** · **판정 편향(위치·자기편애) 방어**. 즉 AI가 맘대로가 아니라 "사람 지식(루브릭) + 사람 검증(보정)"에 앵커링.

## 경계 — 어디까지 자동화되나

- **"깨짐"(broken)** — 대비·오버플로·겹침·회귀 → **거의 완전 자동화.** 렌더만 있으면 뚫린다. 한계 아님.
- **"아름다운가"(taste)** — VLM으로 ~80% 근사, 마지막 한 뼘은 사람. 툴 한계가 아니라 "좋은 디자인"이 부분적으로 주관이라서. 고수들도 사람 리뷰를 없애지 않고 **위치를 올린다** — 깨짐을 자동으로 걸러 사람이 취향만 보게.

## 실행 계획 (이 repo)

지금 갭은 **렌더러 하나**. 순서:

1. **① WCAG 규칙 게이트** ← *지금 착수* — Playwright 설치, 30장 렌더해서 대비·오버플로 자동 검사 → FAIL이면 LLM 재시도 루프. `scripts/visual-gate.js`.
2. **② 비주얼 회귀** — 30장 스냅샷 저장 → 재조립 시 diff. 콘텐츠 고정이라 정확.
3. **③ VLM 심판** — 스크린샷을 세션이 판정(가독·충실도·변별력 루브릭). 회색조 테스트도 여기서.

**현재 상태**: coverage-lint(구조) = 가동 중. 시각 게이트 **① 구현·실행 완료** — `skills/design-style-explorer/scripts/visual-gate.js`(Playwright, WCAG AA 대비 + 오버플로).

### ① 첫 실측 (market-zen 30장, 2026-08-02)

- **오탐 교훈(실물)**: 초판이 `color(srgb ..)`(color-mix 결과)와 그라디언트 배경을 못 다뤄 Material·Y2K를 헛발질(대비 1.0). 파서 수정(srgb float 파싱 + 알파 합성 + 그라디언트 배경 스킵) 후 오탐 제거 — **자동 시각 게이트가 왜 픽셀 샘플링까지 가야 하는지 실증.**
- **살아남은 실제 신호**: PASS 14 · FLAG 16.
  - **가로 오버플로**: style-19(맥시멀 — 카드 회전이 폭 넘침). 명백한 레이아웃 버그, 취향 아님 → 수정 대상.
  - **체계적 저대비**: `.cat.is-sale`(세일 태그, 붉은 소형 글자)가 ~10개 스타일에서 3.0~3.4:1 — AA(4.5) 미달. base 레벨 이슈. 단 "세일=빨강"은 의도라 **더 진하게/크게 vs 브랜드 유지**는 사람 디자인 판단(=취향 경계 실증).
  - `.filter-title`·클레이(15) 등 개별 저대비.
- **경계 재확인**: 오버플로=객관적 버그(고칠 것), 세일 태그 대비=객관적으로 FLAG되나 고칠지는 사람 몫. 게이트는 **"측정·표시"**까지, **결정은 사람/디자인**.

### ② 실측 확장 + detect→fix→verify (fintech A · yeonseo B, 2026-08-02)

- **오버플로 2건 = 명백한 버그 → 수정·검증 green**:
  - D style-19(맥시멀 회전) + A style-18(스위스 12열 그리드 가이드) → `.app{overflow-x:hidden}` → 게이트 재실행으로 제거 확인. **detect→fix→verify 루프 실증.**
- **B `.meta` 타임스탬프 = 실제 가독성 버그 → 부분 수정**:
  - 거의 전 스타일에서 1.0~2.0(읽을 수 없음). 진단: **me 메시지 타임스탬프가 강조색 버블 위 회색**이라 붕괴.
  - 수정: `.meta`를 `--muted`→`color-mix(--ink 72%, --surface)`, me버블은 `color-mix(--bubble-me-ink 90%, --bubble-me-bg)`로 버블 ink에 앵커. 최악 1.0→3.5로 실질 개선.
  - **경계 도달**: 11px 소형 de-emphasized 타임스탬프를 전부 4.5로 올리는 건 (ⓐ 디자인 의도(약한 강조)와 충돌 (ⓑ 잔여 ~1.0은 반투명/color-mix 배경이라 CSS값 측정 한계 = 픽셀 샘플링 필요). → **머신은 표시, 4.5 강행 여부는 사람 디자인 판단.**
- **첫 fix가 불완전 → 게이트가 잡음 → 재수정**한 과정 자체가 verify의 가치(고쳤다고 착각 안 함).

**남은 한계(정직)**: 반투명(alpha<0.5 적층)·color-mix 배경 위 대비는 CSS값만으론 부정확 → 오탐 잔존. **정확한 건 실제 렌더 픽셀 샘플링**(요소 뒤 픽셀 읽기).

### ③ VLM 심판 실행 (market-zen, 2026-08-02)

규칙 게이트가 못 보는 "전체적 품질/다 비슷"을 비전 모델이 판정. `skills/design-style-explorer/scripts/vlm-montage.js`가 30장을 한 장 콘택트시트 PNG로 만들고(개별 완전 로드 후 클립 → 실제 file로 조립, `setContent`는 file:// 이미지 차단이라 안 됨), VLM(세션)이 루브릭으로 채점.

- **하네스 교훈**: 갤러리의 lazy iframe은 스크롤로도 안 잡혀 13~30 백지 → 개별 스크린샷+콘택트시트로 우회. (VLM이 "절반 백지"를 즉시 포착 = 눈이 숫자보다 먼저 봄.)
- **판정 결과**: ① 깨짐 0(오버플로 수정 후) ② 변별력 — 강함 ~17(HUD·터미널·Neubrutal·글래스·DeStijl·Bauhaus·Memphis·스위스·맥시멀…), 약함 ~6, **여전히 비슷 ~7(GOV.UK·shadcn·Braun·네이처·Polaris·웜프로·Ant = 중립 시스템)** ③ 충실도 — DeStijl·Bauhaus·Memphis 등 사조 정의와 일치. → 초기 "18 비슷"이 **~7로 감소**, 잔여는 원래 저구조 사조.

**VLM 재판정으로 후속 개선 유도(2026-08-02)**: VLM이 지목한 잔여 ~7 중립 스타일 중 5종에 authentic 시그니처 저작 → 재판정: **~7 → ~3으로 추가 감소**.
- 07 Braun(오렌지 기능블록)·11 네이처(크림+세이지+유기곡선)·25 Polaris(회색+흰카드+그린)·27 웜프로(웜크림+테라코타+세리프) = 색·처리로 갈림 ✓. 03 shadcn은 크리스프 중립 유지(원래 절제가 정체성).
- 남은 ~3(02 GOV.UK·03 shadcn·30 Ant) = 진짜 미니멀 시스템 사조로 정체성=절제 → 근본 한계. D 구조 시그니처 **26/30**.
- **VLM 심판 → 개선 → 재판정 루프**가 실제로 "다 비슷"을 18→7→3으로 밀어냄. (①규칙이 못 보는 "변별력"을 ③VLM이 잡아 개선 방향 제시.)

### 세 원형 종합 VLM 판정 (D·A·B 전부, 2026-08-02)

세 갤러리 몽타주를 다 판정한 결과 **잔여 "비슷" 클러스터가 세 원형에서 동일한 얼굴**:
- D 컬렉션 ~3(GOV.UK·shadcn·Ant) · A 대시보드 ~6(+Braun·벤토·Carbon·Polaris) · B 대화 ~6(+뉴모·벤토·Carbon)
- **잔여는 항상 중립 시스템 사조**(GOV.UK·shadcn·IBM Carbon·Ant·Polaris·Braun·Neumorphism). 강한 사조(운동·다크·컬러풀)는 세 원형 전부에서 잘 갈림.
- **근본 한계**: 정체성이 "미니멀·중립"인 사조를 억지로 확 다르게 만들면 그 사조가 아니게 됨. A(대시보드)는 KPI·차트·표 배치가 고정이라 라이트 스타일 유사도가 원형 자체에서 더 내재적.
- 결론: **"다 비슷"의 해소 가능한 부분은 다 해소했고, 남은 건 사조의 정체성이자 인정할 한계.** 게이트/VLM은 "여기까지가 한계"를 정직하게 보여주는 역할까지 함.

**세 겹 다 실물로 가동**(①WCAG게이트 ②overflow diff개념 ③VLM콘택트시트). 후속: 픽셀 샘플링(반투명 정확)·② 정식 비주얼 회귀(스냅 저장). **최종 취향·경계 판정은 사람.**
